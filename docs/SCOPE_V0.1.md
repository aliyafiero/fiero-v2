# Fiero V2 lean migration scope

The goal of V0.1 is to get Fiero off Wix and onto a clean, extensible codebase without turning the migration into a months-long product build.

## Build now
- Core positioning and visual refresh
- Modern homepage
- Okta / Entra IAM credibility
- Agentic Enterprise thesis
- Six service routes
- About / Insights / Contact
- GitHub source control
- Cloudflare-ready static deployment

## Defer
- Fiero Labs
- public Okta login demo
- Workflows demo
- agent authorization simulator
- backend APIs / Workers logic
- React
- CMS
- complex forms / CRM

## Why this scope
This version is useful immediately for:
- presenting Fiero more credibly
- sharpening how identity / automation work is described in job interviews
- learning Astro, Git and deployment practices
- creating a platform that can later host real technical demos without rebuilding the site again
